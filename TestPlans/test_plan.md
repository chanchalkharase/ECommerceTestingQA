
# E-Commerce Website Test Plan

## 1. Project Name
E-Commerce Website Testing & Quality Assurance System

## 2. Objective
To verify the functionality, usability, and reliability of an e-commerce website.

## 3. Scope of Testing
- User Registration
- User Login
- Product Search
- Add to Cart
- Checkout

## 4. Testing Type
- Manual Testing
- Functional Testing
- UI Testing

## 5. Testing Approach
Test cases will be prepared and executed manually.
Actual results will be compared with expected results.

## 6. Test Environment
- Operating System: Windows
- Browser: Google Chrome
- Testing Tool: Manual Testing

## 7. Entry Criteria
Test cases and a test environment should be ready.

## 8. Exit Criteria
Planned test cases should be executed and results documented.

## 9. Project Status
Planning Phase
