
# E-Commerce Website Testing & Quality Assurance System

## Project Overview
This project focuses on testing an e-commerce website to identify defects and improve software quality.

## Objectives
- Understand software testing fundamentals.
- Prepare test cases for e-commerce functionalities.
- Identify and report software defects.
- Verify login, registration, search, cart, and checkout functionalities.

## Project Status
Project initialization and planning phase.

## Technologies and Tools
- Git
- GitHub
- Manual Testing
- Test Cases and Bug Reports
